## 🚀 Featured Projects

### 🕊️ Solace: Mental Health Support Marketplace
A full-stack platform connecting clients with verified mental health professionals.

- **Stack:** React.js, TypeScript, Node.js, PostgreSQL, Prisma
- Role-Based Access Control across Client, Professional, and Admin roles
- Human-in-the-loop verification so only credentialed professionals are onboarded
- JWT authentication, bcrypt hashing, and Razorpay payments for booking
- **Serenova**, an in-app AI assistant for navigation and general wellness info (a discovery aid, not a diagnostic tool)

### 💳 Credit Card Fraud Detection: ML Classification
A supervised ML pipeline to flag fraudulent transactions on a real-world Kaggle dataset.

- **Stack:** Python, Pandas, NumPy, scikit-learn
- EDA, feature engineering, and handling severe class imbalance
- Benchmarking Logistic Regression and Random Forest
- Evaluated on precision, recall, and F1-score instead of raw accuracy
